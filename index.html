Why this matters

A browser cannot accept a connection out of nowhere. Before two browsers can talk directly, a short introduction (who you are, how to reach you, a security fingerprint) has to travel between them some other way.

Today every browserCoin introduction goes through two small servers that I run, peer1 and peer2. That makes them a single point of failure. If they go down, links that already exist keep working, but nobody new can join. A network nobody can join slowly dies. A coin that lives in your browser should not depend on one person paying for two servers.

The next release removes that dependency. The introduction can travel two other ways, and either one is enough on its own:

Automatic, through Nostr

Nostr is an open messaging network with hundreds of public relays run by unrelated people. Your browser posts a sealed connection offer there, another browser picks it up, and the two connect directly. The relay only passes the introduction along and is out of the picture once you are connected.

By hand, with a code

No relay at all. You create a short code and send it to a friend over Discord, WhatsApp, email, anything. They paste it and send a reply code back. That is the whole handshake, and there is nothing in the middle that anyone could switch off.

We got the introduction down to about 150 characters, small enough to paste into a chat message. Everything after it travels directly between the two browsers, encrypted.

        Honest limits

        Some networks will not connect

        Strict office firewalls and some mobile carriers block direct links between browsers. The usual workaround is a relay server that forwards all your traffic, which we are deliberately not using. How often this happens in practice is a big part of what this test is for.

        STUN still exists

        To learn its own public address, your browser asks a STUN server (Google, Cloudflare and several others). STUN sees your IP address and nothing else. No messages pass through it, and any of a dozen providers will do.

        This page came from a web host

        Unless you saved it. Use the save button above, open the file from your disk, and it still works. A whole browserCoin node can run the same way.

        Nostr relays see that you are here

        Offers are sealed so the relay firehose does not show your address to casual readers, but anyone who knows this page can read them. If that bothers you, use the code method, which involves no relay at all.
